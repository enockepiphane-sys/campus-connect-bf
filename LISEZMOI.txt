CampusLink — Marché étudiant (livres, documents, services, colocation, matériel)

ÉTAPES
1. Copiez chaque fichier de ce dossier au même emplacement dans votre projet GitHub
   (aucun fichier à supprimer).
2. Exécutez UNE SEULE FOIS dans Supabase (SQL Editor) :
   supabase/migrations/20261103000000_marche_etudiant.sql
   (crée les annonces, les signalements, la modération et le stockage des photos).
3. Poussez sur GitHub : Vercel redéploie tout seul.

FONCTIONNEMENT
- Types d'annonces : Je vends / Je cherche / Je propose un service / Colocation.
- Catégories : Livres, Documents & cours, Services, Colocation & logement, Matériel & autres.
- Tout le monde peut parcourir les annonces. Il faut un compte CampusLink pour publier,
  voir le numéro de contact (WhatsApp / appel) et signaler une annonce.
- AUCUN paiement dans l'application : les étudiants se contactent directement.
- Photos : 3 maximum, réduites automatiquement avant l'envoi (économie de données mobiles).
- Sécurité : 20 annonces actives maximum par personne ; une annonce signalée par 3 personnes
  différentes est masquée automatiquement ; le super admin peut masquer, réafficher, supprimer.
