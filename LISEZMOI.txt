ÉTAPES
1. SUPPRIMEZ sur GitHub l'ancien fichier : src/routes/cours-en-ligne.tsx
   (il est remplacé par src/routes/_commun.cours-en-ligne.tsx ; garder les deux casserait la compilation).
2. Copiez chaque fichier de ce dossier au même emplacement dans votre projet.
3. Exécutez une seule fois dans Supabase (SQL Editor) :
   supabase/migrations/20261102000000_cours_en_ligne_guide.sql
   (crée les cours en ligne, le stockage des fichiers et le guide pré-rempli avec 11 fiches Campus Faso).
4. Poussez sur GitHub.
