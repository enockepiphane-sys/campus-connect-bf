VÉRIFICATIONS ET LIMITES
- Compilation de la copie complète réussie avec les nouvelles pages.
- 5 tests métier réussis (catégories, dates, liens, redirections, PDF).
- Permissions et création/lecture/modification/suppression testées dans une base PostgreSQL isolée : lecteurs sans rôle institutionnel, brouillons privés, favoris privés, admin autorisé, suppression en cascade, accès anonyme refusé.
- Écrans testés avec un service simulé : favoris, détail, administration, sélection PDF, question de cours et téléphone.
- Aucun test connecté à votre base réelle : la mise en service des offres reste à vérifier après exécution du SQL dans votre base existante. Ce fichier SQL ajoute des tables ; il ne déplace aucune donnée et ne crée aucun nouveau projet.
- Le SQL utilise les colonnes deleted_at déjà utilisées par votre application : vérifier qu'elles existent dans etablissements et admins_pre_autorises avant exécution.
- L'analyse TypeScript du projet entier signale des erreurs préexistantes, notamment des types de tables/fonctions manquants. Aucun diagnostic ne concerne les nouveaux fichiers. Ces erreurs n'ont pas été corrigées hors demande.
- Un avertissement de rendu initial a été observé lors de la redirection vers la connexion dans la copie de développement ; le formulaire et les autres flux se sont affichés et ont fonctionné pendant le test simulé. À revérifier après déploiement.
- L'inscription actuelle n'a pas été changée : elle continue d'exiger une préinscription institutionnelle. Le nouveau formulaire de connexion accepte un compte existant même sans rôle institutionnel. La création de nouveaux comptes hors établissement n'est pas ajoutée.
- Aucun appel IA ni résumé/QCM/fiches/corrigé réel : la connexion ultérieure du fournisseur reste nécessaire.
- Les droits de gestion sont étendus aux admins d'établissement actifs et préautorisés, ainsi qu'aux super-admins ; tous peuvent gérer les offres globales. Les accès aux données académiques ne sont pas élargis.
- Une ancienne migration du ZIP d'origine contient des identifiants codés en dur. Elle n'est pas fournie ici. Si ces identifiants servent encore, changez-les dans votre service d'authentification.
